# Final Mini Project Javascript (Admin Dashboard)

Using `json-server` as fake backend, create UI for an admin dashboard with complete CRUD.

## Features

- json server as fake backend 
- users, roles, comments, posts (similar to *https://jsonplaceholder.typicode.com/*)
- interactive menu to switch fields
- field to each resource to move it into trash
- trash page to refresh or confirm resource statement
- implement state of user interface like (loading, empty, error, success)
- disable buttons during loading phase
- paginate results + disable external buttons if there isn't any following page

## Tech Stack
- HTML5
- TailwindCSS (CDN integration)
- Javascript Vanilla
